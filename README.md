# Учебный комплект

Веб-приложение для самостоятельной подготовки студентов: автоматическое преобразование учебных материалов (PDF, TXT или текста лекций) в персональный интерактивный учебный комплект. Приложение готово к работе сразу после открытия — без обязательной регистрации, авторизации и административных барьеров.

## Основные возможности

- **Импорт и предпросмотр источников**:
  - Загрузка **PDF** с текстовым слоем (до **50 страниц**, размер файла до **20 МБ**) через `pdfjs-dist`.
  - Загрузка файлов **TXT** или вставка текста вручную (рекомендуемый объём от 2 000 до 120 000+ символов).
  - Двухэтапное создание комплекта: извлечение и постраничная сегментация текста с предпросмотром и предупреждениями перед генерацией.
- **6 учебных модулей в каждом комплекте**:
  1. **Конспект** (`SummaryView`) — краткое резюме, структурированные разделы с ключевыми тезисами, глоссарий терминов и блок «Обязательно запомнить». Все утверждения снабжены интерактивными ссылками на страницы источника.
  2. **Подкаст** (`PodcastView`) — сценарий образовательного аудиоподкаста с возможностью редактирования текста, серверным синтезом речи и автономным озвучиванием в браузере (Web Speech API).
  3. **Тест для самопроверки** (`QuizView`) — вопросы с вариантами ответов, мгновенной проверкой, разбором ошибок, привязкой к страницам источника и историей попыток.
  4. **Карточки** (`FlashcardsView`) — двусторонние карточки для запоминания с отметками прогресса (`освоено` / `повторить`) и фильтрацией.
  5. **Чат по источнику** (`ChatView`) — учебный тьютор, отвечающий строго по загруженному материалу с указанием цитат и страниц; при отсутствии данных в источнике честно сообщает об этом.
  6. **Исходный материал** (`SourceView`) — полный текст документа с разбивкой по страницам и прямым переходом к нужному фрагменту из любой цитаты (`CitationModal`).
- **Предмет «Медицина» с каталогом из 31 дисциплины**:
  - 5 профильных направлений: морфологические и фундаментальные науки, патология и медикаментозная терапия, терапевтический профиль, хирургический профиль, материнство/детство и реабилитация.
  - Поиск и быстрый выбор медицинской дисциплины при создании комплекта, а также подфильтрация по разделам медицины в каталоге.
  - Предзагруженный демонстрационный комплект: *«Фармакология: Нестероидные противовоспалительные средства (НПВП)»*, а также комплекты по экономике и клеточной биологии.
- **Автономная обработка и серверный шлюз**:
  - Встроенный движок **Open Notebook** (`OpenNotebookEngine`) для локальной семантической генерации конспектов, сценариев подкаста, тестов, карточек и ответов в чате.
  - Серверный режим обработки через `@google/genai` с автоматическим резервным переключением на Open Notebook.
- **Локальное сохранение данных**:
  - Все созданные комплекты, результаты тестов, статус карточек и история чата сохраняются в `localStorage` браузера (`StorageService`).

## Технологический стек

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide React, Motion, Canvas Confetti, `pdfjs-dist`
- **Backend**: Node.js, Express, `tsx`, `@google/genai`, `dotenv`
- **Сборка и инструмент разработки**: Vite 8 (`middlewareMode` в режиме разработки)

## Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example` (при необходимости использования серверного ИИ-шлюза; без ключа приложение продолжит работать через движок Open Notebook):

```env
GEMINI_API_KEY="MY_GEMINI_API_KEY"
APP_URL="MY_APP_URL"
```

### 3. Запуск в режиме разработки

```bash
npm run dev
```

Сервер запустится на порту `3000` (`http://localhost:3000`).

### 4. Проверка типов и сборка для продакшена

```bash
npm run lint    # Проверка TypeScript (tsc --noEmit)
npm run build   # Сборка клиентской части в dist/
npm start       # Запуск продакшен-сервера на Node.js / tsx
```

## Серверные API-маршруты

| Метод | Маршрут | Назначение |
| :--- | :--- | :--- |
| `POST` | `/api/extract-text` | Очистка и постраничная сегментация переданного текста |
| `POST` | `/api/generate/all` | Полная генерация комплекта (конспект, подкаст, тест, карточки) |
| `POST` | `/api/generate/component` | Повторная генерация отдельного модуля (`summary`, `podcast`, `quiz`, `flashcards`) |
| `POST` | `/api/generate/tts` | Серверный синтез аудио для сценария подкаста (с fallback на браузерный TTS) |
| `POST` | `/api/chat` | Ответ на вопрос по учебному материалу с извлечением ссылок на страницы |

## Важные примечания

- Извлечение текста из PDF работает только с файлами, содержащими текстовый слой (отсканированные изображения без OCR не распознаются).
- Учебные материалы, сгенерированные автоматически, снабжаются напоминанием о необходимости сверять ключевые факты и формулировки с первоисточником с помощью интерактивных ссылок на страницы.
